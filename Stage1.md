# 🧠 Beginner Logic Building Problems in C/C++

---

## ✅ Stage 1: No Arrays, No Functions — Just Variables, Loops, and Conditionals

### 🔹 Level 1: Warm-up Problems
1. Print "Hello" 5 times using a loop.  
2. Print numbers from 1 to 10.  
3. Print even numbers between 1 and 50.  
4. Print squares of numbers from 1 to 10.  
5. Take a number as input and print whether it’s positive, negative, or zero.  

---

### 🔹 Level 2: Conditions & Loops Practice
6. Check if a number is odd or even.  
7. Take age as input and print if eligible for vote.  
8. Find the greatest of 3 numbers.  
9. Check whether a number is divisible by both 3 and 5.  
10. Print the multiplication table of any number.  

---

### 🔹 Level 3: Mathematical Logic (No Arrays)
11. Count digits in a number.  
12. Sum of digits of a number.  
13. Reverse a number.  
14. Check if a number is a palindrome.  
15. Check if a number is an Armstrong number.  

---

### 🔹 Level 4: Pattern Problems
16. Print a square of `*` of size N.  
17. Print a right-angled triangle of `*`.  
18. Print a pattern of numbers (like 1, 12, 123, etc.).  
19. Print reverse number pattern.  
20. Print a pyramid pattern using `*`.  

---

### 🔹 Bonus Challenges
21. Check if a number is a prime.  
22. Print all prime numbers between 1 and N.  
23. Find factorial of a number.  
24. Find GCD of two numbers.  
25. Find LCM of two numbers.

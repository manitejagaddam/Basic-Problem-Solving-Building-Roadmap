

# 🚧 Stage 3: Pointers, Structures, and Dynamic Memory

## 🔹 Level 1: Pointers – Fundamentals
1. Print the address of a variable using a pointer.  
2. Swap two numbers using pointers.  
3. Find the sum of array elements using pointers.  
4. Reverse an array using pointer arithmetic.  
5. Count vowels in a string using pointer traversal.  

---

## 🔹 Level 2: Pointers & Functions
6. Pass a variable by reference and modify it in a function.  
7. Pass an array to a function and return the sum of its elements.  
8. Return pointer from a function and access data.  
9. Use pointer to pointer (`int **`) to modify a variable.  
10. Write your own implementation of `strlen()` using pointers.  

---

## 🔹 Level 3: Structures
11. Define a structure for a Student (name, roll, marks).  
12. Read and display data for N students using an array of structures.  
13. Find the student with the highest marks.  
14. Pass a structure to a function and modify its values.  
15. Create a structure for Employee and sort based on salary.  

---

## 🔹 Level 4: Dynamic Memory Allocation (malloc/calloc/realloc/free)
16. Allocate memory for N integers dynamically.  
17. Read N numbers and print their average using dynamic memory.  
18. Use `realloc()` to increase array size at runtime.  
19. Create a dynamic 2D array.  
20. Free dynamically allocated memory and check for memory leaks.
